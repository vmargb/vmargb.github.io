Emacs

  • project-x

    Extends project.el with session persistence and restoration, isolates each project's context using tab-bar-mode.

    karthinks' original post

  • arrow.el

    A port of arrow.nvim. Global, per-project and buffer-local bookmarks on a flat prefix tree, so you choose the keystroke for each mark. Includes an org-mode integration isolated to each project.

    blog post

  • region-pin

    Shows a syntax-highlighted floating snippet of the current definition under your cursor. Acting as a lightweight stand-in for LSP's signature-help.

    blog post

  • indent-guide.el

    Helped optimise and maintain indent-guide.el for drawing vertical indentation guides inside of Emacs.

    blog post (wip)

  • resurface.el

    Brings your buried org-mode notes back for re-reading, scheduled with Leitner boxes and SM-2. As well as an incremental-reading mode.

    blog post

Learning Sciences

  • Myoso

    An Anki-like terminal flashcard app with a multi-step spaced-repetition strategy built on FSRS. I made it because I wanted long chains of thought to fit inside one card.

    blog post 1 blog post 2

  • henle

    A sentence-mining CLI app for language-learning, using a novel technique from the book Henle's Latin

    blog post (WIP)

  • yourepeatme

    A new way to drill hard problems as opposed to traditional flashcards, based on worked-example fading and step-wise theories.

    blog post (WIP)

Other tools

  • funcy.nvim

    A work in progress. A Neovim plugin that uses LSP and regex snippets to generate function and class declarations from calls, like JetBrains does.

  • Lookahead

    A Firefox extension with a keyboard-driven file picker for jumping between your links, so you stop going back and forth to find the right site.
